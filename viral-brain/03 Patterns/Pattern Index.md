# Pattern library

These are **creative hypotheses**, not findings proven from a dataset.

- [[Beat Drop Reveal]] — synchronize the payoff/reveal to a salient sound change
- [[Cold Open Stakes]] — make the viewer understand a high-stakes setup immediately
- [[Reaction Payoff]] — put the human reaction next to the triggering event
- [[Satisfying Loop]] — connect final and first beats so a replay feels natural
- [[Visual Contrast]] — juxtapose expected versus actual / then versus now

After studying at least five examples, add the supporting clip notes and compare against weaker controls. Then update the confidence field.
