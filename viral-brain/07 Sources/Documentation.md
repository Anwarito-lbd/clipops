# Documentation & limitations

- [TikTok Creative Center](https://ads.tiktok.com/creative/creativeCenter/trends): discovery of popular videos, hashtags, and creative inspiration. May require interactive browsing/login for granular views.
- [TikTok Embeds / oEmbed](https://developers.tiktok.com/docs/en/embed-videos): metadata for a supplied public video link; not a discovery/viral metrics crawler. TikTok warns Embed Videos may be deprecated and recommends Embed Player for new integrations.
- [TikTok Research API FAQ](https://developers.tiktok.com/docs/en/research-api-faq): eligibility restrictions (commercial users not eligible) and archived metrics may lag.
- [Obsidian Bases](https://obsidian.md/help/bases): native database view of Markdown frontmatter properties.
- [OpenAI Python library](https://developers.openai.com/api/reference/python): optional analysis of supplied text with a separately billed API key.

No individual TikTok post has been claimed to be viral by this vault without inspection or metrics.
