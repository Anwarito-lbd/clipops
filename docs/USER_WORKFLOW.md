# ClipOps — Daily User Workflow

Ideal loop (manual gates only at the end of each stage):

```text
1. Open ClipOps (http://localhost:3000) and sign in
2. Review recommended campaigns on Home / Operator
3. Approve campaigns (then click Join yourself on Content Rewards)
4. Extension extracts brief/assets OR you upload footage
5. ClipOps transcribes, ranks 10–20 candidates, renders top 3–5
6. Review Approval queue → Approve / Reject / Regenerate
7. Posting queue → Copy caption → Open TikTok → you press Post
8. Paste TikTok URL → Mark posted
9. Open CR submission (extension can highlight Submit) → you confirm
10. Track views/earnings in Tracking
11. When notified, Open Cash-out → you confirm withdrawal
12. Repeat
```

## Morning checklist (~15–25 min)

1. **Scan** Content Rewards with the ClipOps extension (logged-in tab).
2. In ClipOps, review **top 3** → Approve 1–2 HIGH_PRIORITY campaigns.
3. On CR site, **Join** yourself (ClipOps does not auto-join).
4. Collect/download authorised assets → upload into **Assets**.
5. Wait for production queue events → open **Review**.
6. Approve clips that pass compliance.

## Posting block (~20–40 min for 6–9 clips)

For each ready package in **Posting queue**:

1. Download / locate `video.mp4`
2. Copy caption (disclosure + hashtags included)
3. Open TikTok on the correct account
4. You press **Post**
5. Paste URL → Mark posted

## Afternoon / evening

1. Mark submissions after you submit on CR
2. Update views / provisional earnings
3. Check **Payouts / Learn** for cohort tips
4. Hit cash-out only when notified — you confirm

## What ClipOps never does

- Auto-login, CAPTCHA bypass, fake engagement
- Auto TikTok post
- Auto Content Rewards submit / withdraw
- Unattended Playwright against CR (unless you get written permission)

## Month-1 planning assumptions

- 3 accounts × ~2–3 clips/day = 6–9/day ≈ 180–270/month  
- Planning CPM £2, target approval ≥70%, revenue target ~£1,000
